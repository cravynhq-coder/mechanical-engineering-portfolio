# Career & Portfolio Checklist
## Portfolio evidence
- [ ] Clean GitHub profile and pinned repositories.
- [ ] Every project has a readable README, source files, and clear results.
- [ ] Include diagrams/drawings where they help.
- [ ] Explain validation, limitations, and what I learned.
- [ ] No unsupported claims or sensitive personal data.

## CV building blocks (add only when earned)
- Education and verified GPA
- Technical skills demonstrated with evidence
- Projects with measurable outcomes
- Research/competition/workshop contributions
- Internships/experience
- Awards and verified certificates
- Languages
