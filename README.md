# OPERATION ENGINEER 🚀
### Mechanical Engineering → Automotive Engineering → Fully Funded Master's → European Industry → Founder

This repository is the evidence-based operating system for my engineering journey. It is not just a collection of files: **every skill should lead to practice, every project should produce evidence, and every semester should move me closer to the mission.**

## Mission
- Earn an excellent BSME result at IUBAT and protect my CGPA.
- Build strong fundamentals in mathematics, physics, mechanics, thermodynamics, materials, manufacturing, programming, and design.
- Develop an automotive specialization (EVs, vehicle dynamics, powertrain, design, simulation).
- Build a research/project portfolio with credible evidence.
- Prepare for a fully funded Master's abroad (Germany first preference; also investigate other countries/programs).
- Gain industry experience and eventually build an automotive company.

## Operating rules
1. **Academics first:** coursework and exam preparation take priority during semester crunch.
2. **Proof, not claims:** document projects with problem, method, calculations, files, results, limitations, and lessons.
3. **Weekly consistency:** plan the week, review it, and adjust.
4. **Low-cost by design:** prioritize free/open-source tools, resources, and opportunities.
5. **No fake credentials/data:** never claim a certificate, publication, experiment, result, or skill that I have not earned.
6. **Build in public carefully:** keep personal information private; use public portfolio content only.
7. **Learn → apply → document → improve.**
