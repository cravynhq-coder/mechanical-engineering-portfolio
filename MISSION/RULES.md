# Rules of Operation
## Non-negotiables
- Attend classes and labs; use official syllabi and instructor guidance.
- Start assignments early; submit original work.
- Practice problems actively—don't mistake watching videos for learning.
- Keep a mistake log and revisit it weekly.
- Sleep and health are performance inputs, not optional rewards.
- Track time honestly; no fake streaks or fabricated progress.
- Avoid expensive courses/software unless there is a clear, justified return.
- Protect personal data; don't put passwords, ID numbers, private documents, or sensitive family details in this public repository.

## Decision filter
Before adding a task, ask:
1. Does it improve grades, engineering fundamentals, portfolio evidence, funding readiness, or career experience?
2. Is it the highest-priority task this week?
3. Can I finish a small, measurable deliverable?
4. Is the cost acceptable?

## Weekly minimum
- Plan top 3 outcomes.
- Identify upcoming deadlines and exam risks.
- Complete at least one deliberate skill practice session if academic workload permits.
- Review wins, failures, and the next adjustment.
