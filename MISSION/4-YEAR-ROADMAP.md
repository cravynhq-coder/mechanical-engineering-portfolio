# 4-Year Roadmap (12 semesters)
> Use this as a direction—not a rigid prediction. Semester courses and workload must be verified from IUBAT's official curriculum and registration.

## Phase 1 — Build the foundation (Year 1)
**Priority:** excellent grades; mathematics, physics, English, computer literacy; develop study systems.
- [ ] Learn calculus and algebra deeply; maintain a problem-solving notebook.
- [ ] Improve technical English: reading, writing, speaking, presentation.
- [ ] Learn Python fundamentals and spreadsheet skills.
- [ ] Begin CAD with a free tool (FreeCAD) and learn engineering drawing basics.
- [ ] Make 1–2 small, well-documented projects only after coursework is stable.

**Evidence:** solved problem sets, CAD drawings, scripts, course notes, project reports.

## Phase 2 — Engineering fundamentals (Year 2)
**Priority:** mechanics, materials, thermodynamics, manufacturing, electrical fundamentals, numerical methods as taught.
- [ ] Strengthen MATLAB/Python for calculations and visualization.
- [ ] CAD: parametric parts, assemblies, drawings, tolerances.
- [ ] Learn basic measurement, uncertainty, and safe workshop practice.
- [ ] Explore automotive systems; identify a specialization with evidence.

**Evidence:** analytical calculations, small design/build/simulation studies, lab reports.

## Phase 3 — Apply & specialize (Year 3)
**Priority:** deeper engineering, team projects, research literacy, internship readiness.
- [ ] Automotive study track: vehicle dynamics, powertrain, EV systems, control, design.
- [ ] Use simulation only when fundamentals and assumptions are understood.
- [ ] Find faculty research, competitions, internships, or industry projects.
- [ ] Build a project with clear requirements, validation, and a technical report.
- [ ] Start scholarship/program research and document eligibility, deadlines, language, funding.

**Evidence:** one substantial project, technical presentation, CV, research contribution if feasible.

## Phase 4 — Demonstrate readiness (Year 4)
**Priority:** strong final result, capstone, portfolio, applications, references.
- [ ] Choose a capstone aligned with automotive/energy/manufacturing and a real problem.
- [ ] Create a reproducible portfolio: report, drawings/code, test or validation, limitations.
- [ ] Prepare IELTS (or required language exam) based on target programs.
- [ ] Verify funding calls, application costs, documents, and deadlines.
- [ ] Build strong faculty relationships through real academic work.
- [ ] Apply only to verified programs/funding; have a backup plan.

## Every semester
1. Before classes: syllabus map, assessment calendar, baseline diagnostic.
2. Each week: preview → attend → same-day review → practice → spaced revision.
3. Before exams: past questions/teacher guidance, timed practice, error log.
4. End: grade audit, skills audit, project evidence, next-semester adjustment.
