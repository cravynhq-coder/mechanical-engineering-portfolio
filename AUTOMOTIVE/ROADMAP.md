# Automotive Engineering Self-Study Track
Do not let this compete with semester grades. Follow prerequisite order and verify concepts through exercises/projects.

## A. Vehicle fundamentals
- [ ] Vehicle architecture: chassis, body, suspension, steering, braking, tires.
- [ ] Powertrain overview: ICE, transmission, driveline, cooling, lubrication.
- [ ] Electrical/electronic architecture and sensors/actuators.
- [ ] Safety systems and regulations overview.

## B. Core specialist topics (after fundamentals)
- [ ] Vehicle dynamics: longitudinal, lateral, yaw, tire forces, load transfer.
- [ ] Powertrain: engines, transmissions, efficiency, emissions.
- [ ] EVs: battery basics, motor types, inverter, thermal management, charging.
- [ ] Control systems: feedback, modeling, PID, sensors, actuators.
- [ ] Automotive materials, lightweighting, fatigue, manufacturing.
- [ ] CAD design, FEA fundamentals, CFD fundamentals—understand assumptions and validation.

## Suggested project ladder
1. **Vehicle specification calculator:** mass, power-to-weight, energy/fuel estimates; spreadsheet/Python.
2. **Suspension geometry explainer:** CAD sketches and a report on assumptions.
3. **EV range model:** energy consumption, battery capacity, simple scenarios; validate against published data.
4. **Mini vehicle-dynamics model:** bicycle model at a conceptual level; document limitations.
5. **Capstone:** a measurable problem, requirements, design, analysis, validation, and iteration.

For each project: use the project template, keep source files, cite data, and state limitations.
