## Learning loop
1. Pick one skill and a narrowly scoped topic.
2. Use one primary learning resource + practice.
3. Create an artifact (problem set, script, drawing, report).
4. Test/check it; record mistakes.
5. Write a concise README explaining what you can actually do.
